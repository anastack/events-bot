# Events Bot

Telegram-бот для публикации анонсов мероприятий в канал.

## Возможности

- Форма добавления мероприятия: название → дата → место → ссылка
- Предпросмотр поста перед публикацией
- Автоматическая публикация в канал
- Дайджест ближайших мероприятий каждые 2 дня
- Динамическое управление каналами парсера из Telegram без Railway

## Установка

### 1. Создать бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте токен бота

### 2. Подготовить канал

1. Добавьте бота в канал как **администратора** с правом публикации сообщений
2. Узнайте ID канала:
   - Для публичного канала: `@имя_канала`
   - Для приватного: перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot)

### 3. Настроить окружение

```bash
# Установить зависимости
pip install -r requirements.txt

# Создать файл конфигурации
cp .env.example .env
```

Отредактируйте `.env`:

```env
BOT_TOKEN=ваш_токен_от_BotFather
CHANNEL_ID=@ваш_канал
TIMEZONE=Europe/Moscow
DIGEST_HOUR=10
DIGEST_MINUTE=0
ADMIN_IDS=ваш_telegram_id
```

### 4. Запустить

```bash
python bot.py
```

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и список команд |
| `/add` | Добавить мероприятие (форма из 4 шагов) |
| `/upcoming` | Показать ближайшие мероприятия |
| `/digest` | Отправить дайджест в канал (только для ADMIN_IDS) |
| `/cancel` | Отменить текущее действие |
| `/parser_channels` | Показать каналы, которые слушает парсер (для админов) |
| `/parser_add @channel` | Добавить канал в парсер (для админов) |
| `/parser_remove @channel` | Удалить канал из парсера (для админов) |

## Управление каналами парсера

Список хранится в общей базе данных проекта. Значение `PARSER_CHANNELS` используется как начальный список при первом запуске, поэтому существующие каналы сохраняются.

В чате с ботом администратор из `ADMIN_IDS` может использовать (переменная `ADMIN_IDS` обязательна для этих команд):

```text
/parser_channels
/parser_add @hse_events
/parser_remove @hse_events
```

После добавления или удаления парсер обновляет подписки примерно за 30 секунд, перезапуск Railway не требуется. Телеграм-аккаунт Telethon должен иметь доступ к публичному каналу.

## Формат поста в канале

```
🎉 Название мероприятия

📅 Дата: 25 мая 2025, 19:00
📍 Место: Москва, ул. Примерная, 1
🎟 Регистрация / Билеты: Перейти →
```

## Дайджест

Автоматически отправляется каждые 2 дня в указанное время (`DIGEST_HOUR:DIGEST_MINUTE`).
Содержит список всех предстоящих мероприятий, отсортированных по дате.
